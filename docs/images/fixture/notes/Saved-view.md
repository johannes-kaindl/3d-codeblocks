# Saved view

The `view:` key holds a camera angle — a name, or three numbers
(azimuth, elevation, distance; the distance is a factor relative to the fitted
view, so `0.8` is a little closer than "Fit"). The model file itself is never touched.

```3d
file: models/ground-floor.gltf
title: Seen from the south-west
view: 225,28,0.8
height: 420
```
